# Flick

One-tap photo filters in the browser. Pick one or more photos, tap a filter, and save filtered copies back to your phone. The exact aspect ratio and the photo's metadata (date, location, camera info) are kept.

Everything runs on your device. Photos are never uploaded.

## Filters

- **Digicam**: the early-2000s point-and-shoot look. Soft detail, colored shadow noise, crushed blacks, warm/magenta cast, blooming highlights. An orange date stamp is optional. *(in progress)*

## Status

Early setup. The first step is a metadata test page to confirm that iOS Safari keeps a photo's location and date through the web.
