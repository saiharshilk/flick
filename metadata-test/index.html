Flick · metadata test

No filter yet. This checks whether a photo's date and location survive a trip through the browser.

Try both pickers. In the menu, also try Choose File (the Files app) as well as Photo Library. In the photo library, tap Options at the top and turn on Location if you see it.

  1. Pick a photo you know has a location (it shows a map when you swipe up in Photos).
  2. Check the In column: did the location reach the page?
  3. Tap Save to Photos, then Save Image.
  4. In Photos, check: is the copy next to the original (not at today's date)? Swipe up: does it show the map?
  5. Tap Copy report and paste it to Claude, along with what you saw in Photos.
